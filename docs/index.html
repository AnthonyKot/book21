Security Is an Engineering Job

From experienced developer to application and product security in the age of AI.

Learn to investigate a failure, repair its cause and verify the result. These essays connect security reasoning to the software you already know how to build, with worked examples and practice.

Nine essays available. New chapters will extend the path into application security, secure delivery and AI systems.

Start reading

  1. Which security job uses what you already know?

    Choose the responsibility that builds on your engineering experience, and identify the evidence you still need.

  2. A security requirement must survive a hostile input

    Turn a document-export feature into testable rules for identity, permission and changes over time.

  3. Draw the boundary before choosing the control

    Trace who is asking through every component, find where trust changes, and pick controls that fit those crossings.

  4. A valid user can still read the wrong invoice

    Reproduce cross-tenant access in a Spring Boot lab, repair the lookup, and follow the same check into the export worker and download.

  5. A signed token answers only the question you validate

    Reject a valid token intended for another API, then examine purpose, account recovery and the limits of local verification.

  6. The browser brings authority to the request

    Trace a forged form and an injected script through one browser session, and repair each at its actual boundary.

  7. Input becomes dangerous when it changes the grammar

    Trace a title into a SQL predicate, repair its binding, and distinguish injection prevention from tenant authorization.

  8. A fetch endpoint borrows the server’s network access

    Trace an approved URL through a forbidden redirect, verify that the internal service receives no request, and safely restore one allowed hop.

  9. A file becomes a program in the component that opens it

    Trace stored XML into a parser’s file and network access, repair the interpretation boundary, and find the later consumer that still reopens it.

Learn by making a decision

The opening essays use a document-export service to connect roles, requirements and security evidence. Read in order, attempt the exercise, then compare your reasoning with the review notes where provided.
