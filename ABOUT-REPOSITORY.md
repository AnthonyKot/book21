# Security Is an Engineering Job

Book 21: from experienced developer to application and product security in the age of AI.

Read at https://anthonykot.github.io/book21/

The published site includes two essays and the second essay's practice materials. Source Markdown is in `essays/` and `practice/`; generated pages are in `docs/`.

Build: `npm ci && npm run build && npm run check`. GitHub Pages serves `main:/docs`.

Only the public manuscript and site files are tracked. Local author planning and reader-progress records are excluded.
